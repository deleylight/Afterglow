# 这是什么?
   Afterglow 是一款带有互动陪伴体验的 2D 桌面专注工具（番茄钟）。

   我们希望让原本枯燥的专注过程变得温暖起来。你可以与妹妹一起：

   📚 学习 & 工作：开启专属番茄钟，保持沉浸与高效。

   🎮 娱乐 & 休息：合理安排劳逸结合，享受陪伴的时光。

   📊 状态追踪：软件将实时记录你的专注数据，并提供状态提醒与互动。
